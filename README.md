# Библиотека блоков AutoCAD для электротехнических проектов

Данный репозиторий содержит набор параметрических блоков AutoCAD (формат `.dwg`), предназначенных для проектирования систем электроснабжения, автоматизации и распределительных устройств. Блоки включают клеммники, устройства, шкафы, кабели, материалы, листы и другие элементы, используемые в электротехнических чертежах.

## Структура репозитория

```
.
├── et2.dwg          # Блоки для схем этажа 2 (клеммы, устройства, кабели, материалы, лист)
├── kt.dwg           # Блоки шкафов и коробов
├── zzi.dwg          # Блоки контактов, блоков, выносок и коробов
└── README.md        # Описание репозитория
```

## Описание файлов

### `et2.dwg`

Файл содержит блоки, характерные для схем этажа (электрические щиты, клеммники, кабельные соединения). Основные типы блоков:

| Блок | Назначение | Ключевые атрибуты |
|------|------------|-------------------|
| `КЛЕММА1` | Одиночная клемма | `КЛЕММА`, `ЖИЛА`, `КАБЕЛЬ`, `КЛЕММНИК`, `ШКАФ` |
| `Устройство` | Электронное/релейное устройство | `УСТРОЙСТВО`, `ПРОИЗВОДИТЕЛЬ` |
| `КЛЕММА_ВН1`, `КЛЕММА_ВН2` | Внутренние клеммы с привязкой к устройству | `КЛЕММА`, `ВН_ЖИЛА`, `УСТРОЙСТВО` |
| `КЛЕММА1_2КАБ`, `КЛЕММА2`, `КЛЕММА2_2КАБ` | Клеммы для двух кабелей/жил | `КАБЕЛЬ2`, `ЖИЛА2`, `ПРИМЕЧАНИЕ` |
| `REF` | Ссылка на элемент (перекрёстная ссылка) | `ID` (например, `ШУС:KL01:A1`) |
| `КАБЕЛЬ3` | Кабельная трасса между клеммниками | `КЛЕММНИК1`, `КЛЕММНИК2`, `НАПРАВЛЕНИЕ` |
| `Материал` | Описание материала/изделия | `МАТЕРИАЛ`, `ТИП`, `КОЛИЧЕСТВО`, `ЕДИНИЦА` |
| `Лист` | Штамп и формат листа | `ЛИСТ`, `ШИФР`, `Формат`, `Штамп` |

### `kt.dwg`

Файл содержит блоки для монтажа шкафов и коробов:

| Блок | Назначение | Ключевые атрибуты |
|------|------------|-------------------|
| `КОРОБ` | Монтажный короб (размеры X, Y, Z) | `ИМЯ_ТРАССЫ` |
| `ШКАФ` | Шкаф управления/распределения | `ИМЯ`, `НОМЕР`, `МОНТАЖ` |

### `zzi.dwg`

Файл содержит блоки для принципиальных схем и спецификаций:

| Блок | Назначение | Ключевые атрибуты |
|------|------------|-------------------|
| `КОНТАКТ` | Контакт элемента (реле, контактор) | `ИМЯ`, `НОМЕР`, `ТИП`, `МОНТАЖ` |
| `БЛОК` | Функциональный блок (например, реле времени) | `ИМЯ`, `ОБОЗНАЧЕНИЕ`, `КОЛИЧЕСТВО`, `ИНФОРМАЦИЯ` |
| `КОРОБ` | Короб для размещения блоков | `Ширина`, `Высота` |
| `ВЫНОСКА` | Выноска с информацией об элементе | `НОМЕР`, `ИНФОРМАЦИЯ`, `АРТИКУЛ` |
| `НольУстройства` | Маркер нулевого потенциала или источника питания | `ТИП`, `ИМЯ` |

## Использование

1. **Вставка блоков**  
   Откройте нужный `.dwg` файл в AutoCAD. Используйте команду `INSERT` или перетащите блок из Палитры инструментов. Блоки имеют динамические свойства и атрибуты, которые можно редактировать после вставки.

2. **Редактирование атрибутов**  
   Выделите блок → `ATTEDIT` или дважды щёлкните по блоку. Атрибуты (`КЛЕММА`, `УСТРОЙСТВО`, `ШКАФ` и др.) позволяют задавать маркировку, связи между элементами и кабелями.

3. **Параметрические свойства**  
   Некоторые блоки содержат свойства положения, масштаба, видимости (например, `Положение жилы X`, `Видемость жилы`). Изменяйте их через палитру свойств (`PROPERTIES`) или с помощью ручек (grips).

4. **Создание перекрёстных ссылок**  
   Блок `REF` (`et2.dwg`) использует атрибут `ID` для ссылки на другие элементы (например, `ШУС:KL01:A1`). Это позволяет связывать элементы на разных чертежах.

## Версионирование

Все блоки содержат константный атрибут `VERSION = 1.0.0`. При обновлении библиотеки версия будет увеличиваться.

## Примечания

- Блоки созданы в системе единиц **мм**.
- Убедитесь, что стили текста и слои, используемые в блоках, присутствуют в целевом чертеже.
- Для корректного отображения динамических свойств используйте AutoCAD 2013 или новее.
