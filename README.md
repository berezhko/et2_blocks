# Библиотека блоков AutoCAD для проектов электротехнических решений вторичной коммутации

Данный репозиторий содержит набор параметрических блоков AutoCAD (формат `.dwg`), предназначенных для проектирования электротехнических решений вторичной коммутации. Блоки включают клеммники, устройства, шкафы, кабели, материалы, листы и другие элементы, используемые в электротехнических чертежах.

## Структура репозитория

```
.
├── et2.dwg          # Блоки для схем эт2 (клеммы, контакты устройств, устройства, кабели, материалы, лист)
├── kt.dwg           # Блоки шкафов и коробов (предназначены для проектирования кабельных трасс, и расчета длин кабелей)
├── zzi.dwg          # Блоки контактов, устройств, выносок и коробов (предназначены для проектирования схем ЗЗИ)
└── README.md        # Описание репозитория
```

## Описание файлов

### `et2.dwg`

Файл содержит блоки, предназначенные для черчения схемы ЭТ2. Основные типы блоков:

| Блок | Назначение | Ключевые атрибуты |
|------|------------|-------------------|
| `КЛЕММА1`, `КЛЕММА2` | Одиночная клемма | `КЛЕММА`, `ЖИЛА`, `КАБЕЛЬ`, `КЛЕММНИК`, `ШКАФ`, `и прочее` |
| `Устройство` | Электронное/релейное устройство | `УСТРОЙСТВО`, `ПРОИЗВОДИТЕЛЬ`, `и прочее` |
| `КЛЕММА_ВН1`, `КЛЕММА_ВН2` | Контакты устройства | `КЛЕММА`, `ВН_ЖИЛА`, `УСТРОЙСТВО`, `и прочее` |
| `КЛЕММА1_2КАБ`, `КЛЕММА2_2КАБ` | Клеммы для представления в проекте клеммников с двумя кабелями | `КАБЕЛЬ2`, `ЖИЛА2`, `ПРИМЕЧАНИЕ`, `и прочее` |
| `REF` | Ссылка на лист где расположен элемент | `ID` (например, `ШУС:KL01:A1`) |
| `КАБЕЛЬ3` | Блок которые после подготовки КЖ будет инициализирован кабелем | `КЛЕММНИК1`, `КЛЕММНИК2`, `НАПРАВЛЕНИЕ`, `и прочее` |
| `Материал` | Описание материала/изделия | `МАТЕРИАЛ`, `ТИП`, `КОЛИЧЕСТВО`, `ЕДИНИЦА`, `и прочее` |
| `Лист` | Штамп и формат листа | `ЛИСТ`, `ШИФР`, `Формат`, `Штамп`, `и прочее` |

### `kt.dwg`

Файл содержит блоки шкафов и коробов (предназначены для проектирования кабельных трасс, и расчета длин кабелей):

| Блок | Назначение | Ключевые атрибуты |
|------|------------|-------------------|
| `КОРОБ` | Монтажный короб (размеры X, Y, Z) | `ИМЯ_ТРАССЫ`, `и прочее` |
| `ШКАФ` | Шкаф управления/распределения | `ИМЯ`, `НОМЕР`, `МОНТАЖ`, `и прочее` |

### `zzi.dwg`

Файл содержит блоки для проектирования схем ЗЗИ:

| Блок | Назначение | Ключевые атрибуты |
|------|------------|-------------------|
| `КОНТАКТ` | Контакт элемента (реле, контактор) | `ИМЯ`, `НОМЕР`, `ТИП`, `МОНТАЖ`, `и прочее` |
| `БЛОК` | Функциональный блок (например, реле времени) | `ИМЯ`, `ОБОЗНАЧЕНИЕ`, `КОЛИЧЕСТВО`, `ИНФОРМАЦИЯ`, `и прочее` |
| `КОРОБ` | Короб для размещения блоков | `Ширина`, `Высота`, `и прочее` |
| `ВЫНОСКА` | Выноска с информацией об элементе | `НОМЕР`, `ИНФОРМАЦИЯ`, `АРТИКУЛ`, `и прочее` |
| `НольУстройства` | Маркер нулевого потенциала или источника питания | `ТИП`, `ИМЯ`, `и прочее` |

## Версионирование

Все блоки содержат константный атрибут `VERSION = 1.0.0`. При обновлении библиотеки версия будет увеличиваться.

## Примечания

- Блоки созданы в системе единиц **мм**.
- Убедитесь, что стили текста и слои, используемые в блоках, присутствуют в целевом чертеже.
- Для корректного отображения динамических свойств используйте AutoCAD 2013 или новее.
